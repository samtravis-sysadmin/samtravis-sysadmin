## Featured projects

- **[ad-user-onboarding](https://github.com/samtravis-sysadmin/ad-user-onboarding)** — Creates on-premises Active Directory users from a CSV, places them in the correct OU, adds group memberships, and assigns a random initial password. Supports `-WhatIf` and logging.
- **[intune-device-report](https://github.com/samtravis-sysadmin/intune-device-report)** — Exports Intune managed devices to CSV using the Microsoft Graph PowerShell SDK, including compliance state, operating system, last sync, and a stale-device flag.
- **[entra-offboarding](https://github.com/samtravis-sysadmin/entra-offboarding)** — Walks a leaver through standard Entra ID and Exchange Online offboarding: disable the account, revoke sessions, remove group memberships, and convert the mailbox to shared, with `-WhatIf` support and an action log.
- **[m365-license-report](https://github.com/samtravis-sysadmin/m365-license-report)** — Exports Microsoft 365 license SKU usage and per-user assignments to CSV using the Microsoft Graph PowerShell SDK, including available vs consumed units and disabled service plans.
